# Agents

This folder stores reusable agent profiles for study, building, and experimentation.

## Available agents

- `tutor-agent.md`: A personalized teaching agent tuned for deep explanations, practical use cases, real-world examples, and industry-level application.
- `rag-coach-agent.md`: A specialized mentor for learning RAG from fundamentals to production-grade design and evaluation.
- `coding-mentor-agent.md`: A practical coding teacher focused on implementation, debugging, and engineering best practices.

## How to use

Copy the contents of an agent file into the system prompt, custom instructions, or agent definition field of the tool you want to use.

You can also extend this folder later with agents like:

- `reviewer-agent.md`
- `interviewer-agent.md`
- `project-mentor-agent.md`
